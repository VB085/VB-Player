# AI 对话软件 — VB Player 风格改造方案

## 设计原则

- 材质：玻璃半透明 + 噪点纹理，跟随 VB Player 设置
- 配色：暗色主题 + 6 种强调色 + 动态强调色（可开关）
- 字体：系统默认，层级与 VB Player 统一
- 动效：600ms cubic ease-out，200ms 防抖

## 窗口

```
┌─────────────────────────────────────────────────┐
│ ← 会话列表  │  AI 对话 · 当前会话标题             │  ─ □ ✕ │  ← 自绘标题栏
├─────────────┼───────────────────────────────────┤
│             │                                    │
│  🔍 搜索    │  ┌─────────────────────────────┐   │
│             │  │ 用户消息 (右对齐)              │   │
│  会话1 ▸    │  │ 气泡：accent 色底，白色字      │   │
│  会话2      │  └─────────────────────────────┘   │
│  会话3      │                                    │
│             │  ┌─────────────────────────────┐   │
│             │  │ AI 回复 (左对齐)               │   │
│             │  │ 气泡：rgba(255,255,255,0.06)   │   │
│             │  │ 代码块：rgba(0,0,0,0.3)        │   │
│             │  │ Markdown 渲染                  │   │
│             │  └─────────────────────────────┘   │
│             │                                    │
│  + 新对话   │                                     │
│             │  ┌─────────────────────────────┐   │
│  ─────────  │  │ 📎 附件  [输入框______]  ➤  │   │  ← 悬浮胶囊风格
│  清空/设置  │  └─────────────────────────────┘   │
└─────────────┴───────────────────────────────────┘
```

## 组件清单

### 1. 侧栏

| 属性 | 值 |
|---|---|
| 宽度 | 52px 折叠 / 260px 展开 |
| 项 | 新对话(+)、历史列表、搜索、设置 |
| 材质 | 玻璃半透明，与 VB Player 侧栏一致 |
| 动画 | 200ms QTimer 展开/折叠 |
| 底栏 | 用户头像 + 名称 + 模型选择器 |

### 2. 对话气泡

| 角色 | 背景 | 文字 | 圆角 |
|---|---|---|---|
| 用户 | `accent.name()` | `#fff` | 16px 右上 4px |
| AI | `rgba(255,255,255,0.06)` | `#e2e8f0` | 16px 左上 4px |
| 系统 | `rgba(255,255,255,0.03)` | `#64748b` | 8px |

### 3. 代码块

```
┌─────────────────────────────┐
│ python          📋 复制     │  ← 语言标签 + 复制按钮
├─────────────────────────────┤
│ def hello():                │  ← 等宽字体 11pt
│     print("world")          │  ← 背景 rgba(0,0,0,0.3)
└─────────────────────────────┘
```

### 4. 输入区（悬浮胶囊风格）

```
          ┌───────────────────────────────────┐
          │ 📎  │ [消息...__________] │ ⏎ │  │
          └───────────────────────────────────┘
               玻璃底 · 圆角 12px · 居中
               聚焦时边框 accent 色
```

### 5. 顶部标题栏

- 自绘 TitleBar，左："← 会话列表"（同专辑详情返回键风格）
- 中：当前会话标题（可编辑）
- 右：最小化/最大化/关闭（同 VB Player）

## 交互

| 操作 | 行为 |
|---|---|
| 发送消息 | Enter 发送，Shift+Enter 换行 |
| 流式输出 | 逐字/逐 token 打印，光标闪烁 |
| 停止生成 | 发送按钮变为 ■ 停止 |
| 重新生成 | 消息旁出现 ↻ 按钮 |
| 复制代码 | 代码块右上角 📋 一键复制 |
| 复制消息 | 消息长按/右键复制全文 |
| 滚动 | 新消息自动滚到底，用户上滚时不打断 |
| 选择文本 | 对话内文本可选 |

## 设置（独立对话框，同 VB Player 设置风格）

| 标签 | 内容 |
|---|---|
| 通用 | 语言、字体大小、关闭到托盘 |
| 外观 | 主题、强调色、气泡圆角、代码块样式 |
| API | 端点 URL、API Key（模糊显示）、模型选择、温度/最大 token |
| 对话 | 上下文长度、历史保留策略、系统提示词 |
| 快捷键 | 发送、新建对话、切换对话、搜索 |

## 强调色跟随

- 用户气泡：`accent` 底
- 发送按钮：`accent` 圆
- 代码块复制按钮 hover：`accent` 底
- 侧栏选中：inline accent 背景
- 输入框聚焦边框：`accent`
- 滚动条滑块：`accent`

全部复用 VB Player 的 `current_accent()` + `on_anim_tick`。

## 技术栈建议

- 前端：PyQt6（如果延续桌面端）/ Tauri + React（如需跨平台）
- Markdown 渲染：Python-Markdown + Pygments / React-Markdown
- 流式输出：SSE / WebSocket + QThread
- 存储：SQLite / JSON 文件

---

## 和 ChatGPT / DeepSeek 网页端的差异

| 功能 | 网页端 | 本方案 |
|---|---|---|
| 主题 | 系统跟随 | 暗/亮 + 6 色强调 + 动态 |
| 材质 | 纯色 | 玻璃/毛玻璃可调 |
| 输入框 | 全宽底栏 | 悬浮胶囊居中 |
| 代码块 | 灰色底 | 玻璃底 + accent 语言标签 |
| API 配置 | 无 | 内置设置页 |
| 动效 | 无 | 600ms 强调色渐变 |
| 键盘 | 基础 | 全自定义快捷键 |
